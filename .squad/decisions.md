### D-002: Auth Crypto Architecture
**Author:** Gus | **Date:** 2026-05-10 | **Status:** Implemented

- Dual-encryption: same HMAC secret encrypted twice under different keys (WebAuthn wrapper key + PBKDF2 PIN key)
- WebAuthn path: random AES-256 wrapper key in localStorage, gated by biometric
- PIN path: PBKDF2 100k iterations, SHA-256, random 16-byte salt
- Plaintext secret held in-memory only (session.js / AuthContext)
- localStorage keys: `receipts_credential_id`, `receipts_webauthn_key`, `receipts_webauthn_encrypted_secret`, `receipts_pin_encrypted_secret`, `receipts_pbkdf2_salt`, `receipts_apps_script_url`, `receipts_setup_complete`

### D-005: API & Cache Layer Architecture
**Author:** Gus | **Date:** 2026-05-10 | **Status:** Implemented

- CryptoKey caching: imported HMAC CryptoKey cached at module level in `auth.js`, cleared only when secret string changes. Avoids repeated `importKey` calls during a session.
- Stale-while-revalidate via fire-and-forget: `cachedFetch` returns stale data immediately and triggers background `fetch`. `onCacheUpdate` listener Set notifies hooks when background refresh completes for re-render.
- Dynamic month TTL: `fetchMonth` computes TTL by comparing requested month key against current `YYYY-MM`. Current month = 2 min, previous = 1 hour, older = 24 hours.
- Cache key prefix: all IndexedDB entries use `receipts_cache_` prefix so `clearAllCache` can enumerate only our entries.
- Hooks use ref for fetchFn: `useApiData` stores fetch function in `useRef` so effect only re-runs when serializable deps change, preventing infinite loops.
- No external crypto: all signing uses `crypto.subtle`. Hex encoding is a manual loop — no dependency needed.
- Files: `src/api/auth.js`, `src/api/cache.js`, `src/api/sheets.js`, `src/api/hooks.js`

### D-006: Phase 2 Offline & PWA UI Components
**Author:** Jesse | **Date:** 2026-05-10 | **Status:** Implemented

- OfflineBanner: fixed top banner, CSS slide animations, auto-detects online/offline via window events or accepts isOnline prop.
- PullToRefresh: touch gesture wrapper, 60px threshold, dampened pull with 0.5 resistance, green spinner.
- SyncIndicator: status dot + label, 60s auto-refresh, color-coded (green/yellow/orange). Standalone — designed for OverviewTab header.
- InstallPrompt: iOS Safari only, 3-step A2HS instructions, `receipts_install_dismissed` localStorage key, permanent dismiss, 2s delay.
- All animations CSS keyframes (consistent with D-004, no JS motion libraries).
- OfflineBanner and InstallPrompt live inside MainApp (inside auth gate).
- PullToRefresh is a generic wrapper — consumers pass onRefresh and disabled props.
